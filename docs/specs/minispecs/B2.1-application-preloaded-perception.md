# B2.1 application-side preloaded perception

Status: Accepted for application-side release and live DFHack promotion.

This slice implements the v0.2.1 behavior with a promoted read-only DFHack
current-scene payload:

- `CurrentSceneObservation` is a validated, versioned application contract.
- Fake mode returns a deterministic 33 x 33 current-level map and bounded site
  overview with hidden-cell redaction.
- Every chat turn attempts current-scene acquisition before the first provider
  request. Expected adapter unavailability becomes an explicit unavailable
  marker and receipt; invalid scene data fails before provider invocation.
- All normal turns use `IDwarfAgent` with `inspect_stocks`, `list_dwarves`, and
  `inspect_dwarf`. The legacy `look_around` contracts remain only as migration
  artifacts and are not exposed on this normal path.
- FSMP/1 formatting and canonical colour rows are deterministic and bounded to
  8192 characters. Prompt-provider text and the stored safe preview are
  separate; the latter contains only scene metadata and `[redacted]` content.
- The API and frontend render current-scene receipts separately from optional
  model-selected tool receipts.

## Live adapter gate

The `get-dwarf-surroundings` Lua command includes the bounded current-scene
path and is promoted with this release. The v0.2.1 live adapter invokes that
path with the validated observer ID and reports expected scene unavailability
when DFHack is unavailable or returns invalid data.

Human decision, 2026-07-16: the application-side implementation and retained
research evidence are accepted. Release authorization recorded on 2026-09-05
authorizes live promotion of the reviewed read-only command. The remaining
R2.1-001 gaps stay tracked as follow-up validation in the research report.
