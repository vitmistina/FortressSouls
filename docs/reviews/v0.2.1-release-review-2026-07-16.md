extraction path.

2. final surface-sampling algorithm and version-metadata approval.

These are follow-up checks and are not represented as completed live smoke
evidence. The retained evidence and probe source are documented in

## Release boundary

This review accepts the application-side v0.2.1 behavior and authorizes live
DFHack current-scene support for the promoted command. Runtime operators must
still complete the documented follow-up checks before changing the extraction
algorithm or version metadata.
